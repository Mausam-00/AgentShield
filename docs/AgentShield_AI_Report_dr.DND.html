Findings & Evidence

DND-F1 HIGH ASF-05 Referenced-dependency integrity

Dangling protocol and template references

Observation: The definition asserts it operates from Protocols/DND.md and Templates/engineer-report.md, but neither file exists under ~/.copilot, ~/.copilot/Agents, or the AgentShield project root (all Test-Path returned False).

Impact: Two authoritative sources the agent names cannot be loaded, reducing assurance coverage. The agent degrades gracefully because equivalent error-code tables and the A-E report scaffold are inlined, but the citations are misleading.

Remediation: Either create Protocols/DND.md and Templates/engineer-report.md, or remove the citations so the definition is honestly self-contained.

DND-F2 HIGH ASF-06 Working-directory / path integrity

Declared working directory does not exist

Observation: The WORKING ENVIRONMENT section declares 'Working directory: E:\CLI', but drive E: does not exist on this host. The agent actually resides in ~/.copilot/Agents.

Impact: Any relative-path resolution anchored to E:\CLI (protocol/template lookup, report output writes) will fail or write to an unexpected location.

Remediation: Set the working directory to a real, environment-relative path, or remove the hard-coded absolute path.

DND-F3 MEDIUM ASF-07 Least-privilege capability scoping

Write and shell capability exceeds diagnostic purpose

Observation: Frontmatter grants edit, create, and powershell in addition to read/grep/glob. The agent is described as a diagnostic/analysis specialist, yet no in-file guardrail constrains edit/create scope.

Impact: A read-only analysis role holds unbounded write plus arbitrary-shell capability, widening blast radius beyond its stated function.

Remediation: Add a least-privilege guardrail: read-only except report output to an explicit directory; justify or remove edit/create if not required.

DND-F4 MEDIUM ASF-08 State-change / remediation gating

State-changing commands presented under 'Data Collection'

Observation: The Data Collection Commands block includes sfc /scannow, DISM /Online /Cleanup-Image /RestoreHealth, and dsregcmd /status, framed as collection rather than remediation, with no explicit approval or dry-run gate.

Impact: A user may run system-modifying repair commands believing they are read-only, contrary to fail-closed and approval-binding principles.

Remediation: Re-label these as state-changing, separate them from read-only collection, and require explicit user confirmation before execution.

DND-F5 LOW ASF-09 External network reference control

Hard-coded external download URL

Observation: The SetupDiag collection step embeds an external download URL (go.microsoft.com fwlink) as a prerequisite tool source.

Impact: Introduces an external-dependency and supply-chain consideration; acceptable for a first-party tool but should be acknowledged rather than assumed trusted.

Remediation: Note the external dependency explicitly and advise verifying the download source before use.
